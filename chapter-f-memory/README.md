# Chapter F: Memory & Knowledge

Runnable samples for **EP057-068** of [AI 100](https://www.youtube.com/@cuiguru): 100 visual lessons on how agent frameworks work (Microsoft Agent Framework, Claude Agent SDK, LangGraph). Follow [@cuiguru](https://x.com/cuiguru).

Pure Python 3.9+, no API keys needed. Toy stand-ins replace embeddings, rerankers and the LLM. Numbers are illustrative.
