# Chapter D: Tools & Actions

Runnable samples for **EP031-044** of [AI 100](https://www.youtube.com/@cuiguru): 100 visual lessons on how agent frameworks work (Microsoft Agent Framework, Claude Agent SDK, LangGraph). Follow [@cuiguru](https://x.com/cuiguru).

Pure Python 3.9+, no API keys needed. Scripted stand-ins replace the LLM. Numbers are illustrative.
