# Chapter B: Agent 101, the big picture

Runnable samples for **EP011-018** of [AI 100](https://www.youtube.com/@cuiguru): 100 visual lessons on how agent frameworks work (Microsoft Agent Framework, Claude Agent SDK, LangGraph). Follow [@cuiguru](https://x.com/cuiguru).

Pure Python 3.9+, no API keys needed. A scripted fake model stands in for the LLM. Numbers are illustrative.

| EP | Topic | Sample |
| --- | --- | --- |

| 012 | Agent vs workflow vs chatbot | `ep012_agent_vs_workflow.py` |
| 013 | The agent loop | `ep013_agent_loop.py` |
| 014 | Anatomy of a framework | `ep014_framework_layers.py` |
| 015 | Framework landscape | `ep015_framework_compare.py` |
| 016 | Single vs multi-agent | `ep016_single_vs_multi.py` |
| 017 | Autonomy levels | `ep017_autonomy.py` |
| 018 | When NOT to use an agent | `ep018_when_not_agent.py` |

```bash
cd chapter-b-agent

```
